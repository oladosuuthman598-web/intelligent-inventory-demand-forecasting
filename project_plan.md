# Project plan

## Confirmed project definition
- Unit of analysis: product-level daily demand
- Forecast horizon: seven days
- Target: units sold

## Milestones
- [ ] Record dataset source, licence, fields, and date coverage.
- [ ] Load and inspect the dataset.
- [ ] Check data types, missing values, duplicates, and date continuity.
- [ ] Define product/date aggregation rules.
- [ ] Complete exploratory data analysis.
- [ ] Create a time-aware train/validation/test split.
- [ ] Establish a baseline forecast.
- [ ] Train candidate models.
- [ ] Evaluate with MAE and RMSE; justify additional metrics.
- [ ] Interpret results and document limitations.
- [ ] Write a reproducible project report.

## Experiment log
For each experiment, record: date, question, data/features, validation design, model, metrics, observations, and next step.
