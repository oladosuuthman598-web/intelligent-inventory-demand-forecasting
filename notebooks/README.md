# Notebooks

Use this directory for Jupyter notebooks documenting exploration, experiments and results.

Suggested sequence:
1. `01_data_understanding.ipynb` — inspect the dataset, columns, date coverage and data quality.
2. `02_exploratory_analysis.ipynb` — visualise demand patterns and investigate trends or seasonality.
3. `03_baseline_forecasting.ipynb` — create benchmark forecasts.
4. `04_model_experiments.ipynb` — train and compare forecasting approaches.
5. `05_forecast_evaluation.ipynb` — assess performance on a chronological holdout period.

Keep notebooks readable, explain important decisions in Markdown cells, and restart/run all cells before committing. Do not commit large datasets or sensitive information.
