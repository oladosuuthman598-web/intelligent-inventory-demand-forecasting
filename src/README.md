# Source code

Place reusable Python modules and scripts in this directory as the project develops.

Possible modules:
- `data_prep.py` — data validation and preparation.
- `features.py` — feature engineering.
- `baselines.py` — baseline forecasting methods.
- `train.py` — model training.
- `evaluate.py` — forecast evaluation.

These are suggestions, not existing implementations. Keep exploratory work in `notebooks/` and move stable, reusable logic here when needed.
